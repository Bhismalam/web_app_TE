# Memory

Folder ini berisi catatan yang perlu diingat lintas sesi kerja: preferensi, fakta proyek, dan progres yang belum tentu terlihat dari kode.

Contoh isi:
- `preferences.md` — preferensi cara kerja/gaya coding
- `project-facts.md` — fakta penting proyek (stack, batasan, target rilis)
- `log.md` — catatan progres/keputusan per tanggal
