# Context

Folder ini berisi catatan konteks proyek: tujuan, batasan, keputusan arsitektur, dan referensi eksternal yang relevan.

Contoh isi:
- `overview.md` — deskripsi singkat proyek, tujuan, target pengguna
- `decisions.md` — keputusan teknis penting beserta alasannya
- `references.md` — link/dokumen eksternal yang jadi acuan
